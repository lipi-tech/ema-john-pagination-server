# Ema-John Pagination Client

A React-based e-commerce client application built with Vite. Users can browse products, search items, add products to the cart, and navigate through paginated product listings.

## Features

- Product listing
- Product search and sorting
- Pagination
- Add to cart functionality
- Cart data persistence with localforage
- Client-side routing with React Router

## Tech Stack

- React
- Vite
- React Router DOM
- localforage
- match-sorter
- Font Awesome

## Installation

1. Clone the repository:

```bash
git clone https://github.com/lipi-tech/ema-john-pagination-client.git
```

2. Go to the project folder:

```bash
cd ema-john-pagination-client
```

3. Install dependencies:

```bash
npm install
```

## Run the Project

```bash
npm run dev
```

Then open your browser and visit:

```bash
http://localhost:5173
```

## Build for Production

```bash
npm run build
```
